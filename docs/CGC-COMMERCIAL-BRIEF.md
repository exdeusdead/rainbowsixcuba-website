# Rainbow Six CUBA · propuesta comercial CGC

Estado: pre-diseño comercial bilingüe para revisión de CGC  
Repositorio: `exdeusdead/rainbowsixcuba-website`  
Idiomas incluidos: español e inglés  
Idiomas adicionales: alcance y precio separados  
Modelo: tarifa comercial; no utiliza el modelo familiar de otros websites en desarrollo.

## Decisión de producto

Rainbow Six CUBA ya tiene una base de comunidad, eventos, competición, estadísticas, coaching, alianzas y Companion. La propuesta no lo trata como una landing genérica: lo posiciona como un hub operativo de esports que puede crecer por fases.

La plantilla de presentación es consistente con el catálogo CGC —propuesta, paquetes, alcance, extras y base de precio—, pero el producto conserva una identidad esports propia y una arquitectura más orientada a módulos, datos y operaciones.

## Paquetes orientativos

| Paquete | Precio único | Esfuerzo de planificación | Alcance principal |
| --- | ---: | ---: | --- |
| Community Launch | US$3,200 | 40 h | Hub responsive, ES/EN, contenido base, CTA de Discord, módulos comunitarios y QA de lanzamiento |
| Competitive Operations | US$6,800 | 78 h | Launch + eventos, competición, perfiles, scoreboard, estructura de estadísticas y superficie lista para API |
| Ecosystem Platform | US$12,900 | 138 h | Operations + autenticación, flujos de cuenta, integración de datos, alianzas, partners y handoff operativo |

Estos importes son precios de catálogo para un proyecto comercial comparable, no una promesa de coste cerrado para cualquier cliente. El paquete definitivo se confirma después del descubrimiento, inventario de contenidos, integraciones y requisitos de operación.

## Cómo se justifican

La referencia externa más directa es la guía de precios de Clutch actualizada en septiembre de 2026: registra tarifas de empresas de diseño web de aproximadamente US$100–149/h, indica que la mayoría de proyectos revisados cuesta menos de US$10,000 y diferencia los constructores, que aparecen alrededor de US$25–49/h. También reporta que el promedio de los proyectos revisados es mucho mayor cuando aumenta el tamaño y la duración del alcance. Ver [Clutch, Web Design Company Pricing Guide](https://clutch.co/web-designers/pricing).

El Bureau of Labor Statistics de Estados Unidos publica como contexto laboral una cifra rápida de US$47.85/h y un salario mediano de US$99,520 para desarrolladores y diseñadores digitales; el mismo documento distingue entre interfaces, desarrollo, pruebas, navegación, gráficos e integraciones. No se usa ese salario como tarifa facturada: sirve para evitar subestimar el trabajo técnico y de diseño. Ver [BLS, Web Developers and Digital Designers](https://www.bls.gov/ooh/computer-and-information-technology/web-developers.htm).

La hipótesis interna de este catálogo es una tarifa equivalente de planificación de aproximadamente US$80–94/h, sin presentarla como una tarifa horaria al cliente:

- Community Launch: US$3,200 / 40 h = US$80/h equivalente.
- Competitive Operations: US$6,800 / 78 h = US$87.18/h equivalente.
- Ecosystem Platform: US$12,900 / 138 h = US$93.48/h equivalente.

El precio aumenta porque el producto pasa de presentación y conversión a coordinación de eventos, visualización de datos, identidad, autenticación, integraciones, pruebas de estados y handoff. La complejidad funcional, no el número de páginas por sí solo, es el criterio principal.

## Incluido en todos los paquetes

- Español e inglés con selector visible y contenido realmente traducido.
- Diseño responsive, contraste revisado, navegación de teclado razonable y estados vacíos identificables.
- Estructura de contenido y CTA coherentes con la fase contratada.
- Repositorio privado canónico de GitHub, build reproducible y publicación controlada en Sites.
- QA de la ruta oficial de revisión antes de presentar el website como terminado.

## Extras comerciales

- Idioma adicional: desde US$650 por idioma para una superficie de contenido acotada; puede subir a US$1,500 o más si incluye módulos, datos, revisión editorial y QA completo.
- Integraciones externas, autenticación avanzada, API de estadísticas, automatizaciones, CMS, pagos y operaciones de torneo: cotización separada.
- Dominio, correo, servicios de terceros, licencias, traducción profesional certificada y mantenimiento continuo: no incluidos salvo que el alcance lo indique.
- El cumplimiento de marca, licencias de juego y uso de activos de terceros requiere aprobación del cliente y no se presume incluido.

## Límites de la propuesta

El website actual contiene módulos beta y flujos que deben seguir conectándose a servicios reales. Una pantalla convincente no equivale a una API operativa, un sistema de torneo o una autorización de Ubisoft. La revisión de CGC debe distinguir siempre entre superficie publicada, integración funcional y roadmap.
