Accesibilidad / Accessibility

Estado de accesibilidad de la previsualización. La base actual no equivale a una declaración de conformidad WCAG ni a una auditoría de producción.

ES EN

Medidas actuales

La navegación usa encabezados, botones, enlaces, etiquetas, estados vacíos y controles de teclado; las vistas de datos permiten desplazamiento horizontal cuando la tabla lo necesita.

Limitaciones conocidas

Los paneles dinámicos dependen de JavaScript y algunas superficies beta siguen siendo demostraciones. El contenido visual y la operación con lectores de pantalla, zoom y contraste requieren revisión específica de lanzamiento.

Estado de lanzamiento

La accesibilidad permanece en mejora continua junto con contenido, responsables, soporte y procesos reales. Esta demo no debe presentarse como un servicio de producción plenamente auditado.

Current measures

Navigation uses headings, buttons, links, labels, empty states and keyboard controls; data views allow horizontal scrolling when a table needs it.

Known limits

Dynamic panels depend on JavaScript and some beta surfaces remain demonstrations. Visual content and operation with screen readers, zoom and contrast settings still require a release-specific review.

Launch status

Accessibility remains part of the ongoing work alongside content, ownership, support and real operating processes. This demo must not be presented as a fully audited production service.
